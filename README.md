# THRU NORTH — STAY AHEAD. BE SMART.

Philippine K-12 Educational Mastery Operating System built with React, Vite, TypeScript, and Tailwind CSS.

## Features
- **Student Portal**: Continuous constructivist spiral competency tracking, mastery quotient ring indicator, diagnostic retention decay alerts, interactive micro-quizzes with immediate pedagogical feedback.
- **Teacher Portal**: Section selector, qualitative cohort formative observation logger, DepEd competencies heatmap, permanent record (SF10) exporter.
- **Admin Portal**: Institutional telemetry, dual-stack runtime architecture (MATATAG & Legacy K-12), on-premises school local hub node sync.
- **Parent Portal**: Real-time learner progress, DepEd quarter equivalents, verified intervention status, direct faculty observations and feedback.
- **AI Socratic Tutor**: Socratic reasoning guidance without direct answers to encourage step-by-step critical thinking.
- **AI Content Studio**: DepEd Order No. 10 s. 2024 compliant Learner Activity Sheets (LAS) and formative diagnostic specimen generator.
- **Strict Visual Design System**:
  - **Day Mode (Default)**: Crisp Pearl White (`#F8F9FA`), Layered Translucent Surfaces, Acrylic Black (`#0A0A0A`), Charcoal Gray (`#4A4A4A`), and Strictly Electric Blue (`#0052FF`) buttons.
  - **Adaptive Dark Mode**: Deep Acrylic Black (`#050505`) with pure Pearl White text.

## Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
